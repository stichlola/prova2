# Sito Plutone — Riaccendiamo le vetrine

Versione statica (HTML/CSS/JS) del sito Canva di Plutone, con lo stesso stile grafico.

Pagine: `index.html` (Home), `clienti.html` (Apri uno Spazio), `proprietari.html` (Proponi un Immobile), `mission.html`, `faq.html`, `privacy.html`, `404.html`.

Immagini: copia il contenuto della cartella `png` (loghi e foto) dentro `docs/assets/img/`, mantenendo nomi e sottocartelle (`home_page/`, `clienti_page/`, `proprietari_page/`). Finché un'immagine manca, il sito mostra un riquadro blu segnaposto.

Per vederlo: apri `index.html` nel browser, oppure attiva GitHub Pages (Settings → Pages → branch, cartella `/docs`).
